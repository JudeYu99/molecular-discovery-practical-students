Day 1 · guided activity

PyMOL practical

Work through two experimental structures of the same mouse Abl kinase domain. The first contains imatinib. The second contains PD173955. Use them to practise navigation, pocket selection, contact inspection and structural comparison. Record your own observations as you work.

Before opening PyMOL

Save both PDB files in one folder. Start with 1IEP, which contains imatinib as ligand STI. Add 1M52 only at Step 5, where you will compare its ligand P17. Both files contain two protein chains, so focus on chain A throughout. Keep the original files unchanged.

Step 1

Load and navigate

First establish which structure and ligand instance you are viewing.

  1. Open 1IEP.pdb in PyMOL using the File menu. Find its name in the object panel.
  2. Rotate the structure, zoom towards it and move it across the screen. Use the mouse guide displayed in PyMOL if the controls differ on your laptop.
  3. Show the sequence panel using Display → Sequence. Locate the protein chain and the bound ligand. Check whether the file contains more than one protein chain or ligand copy.
  4. Find imatinib in chain A. In this PDB file its residue name is STI and its residue number is 201. Notice the second protein and ligand copy in chain B.

Record: Which chain and ligand copy are you using? What does the PDB entry report as the experimental method and resolution?

Check: You can return to a whole-protein view and identify STI A 201 unambiguously.

Step 2

Choose representations

Use different views to answer different structural questions.

  1. Display the protein as a cartoon. Colour each chain differently if the structure has several chains.
  2. Display STI A 201 as sticks. Identify its oxygen and nitrogen atoms by their colours.
  3. Temporarily show spheres for any waters or metals near the ligand. Distinguish these from protein atoms and from the ligand.
  4. Try a protein surface, then hide it again when it obscures the pocket. Keep a clean cartoon-and-sticks view for the next activity.

Think: Which representation best shows the fold? Which best shows the ligand's atomic contacts?

Check: Your view makes chain A, STI and nearby waters distinguishable.

Step 3

Show the binding site

Select a single ligand and complete protein residues within 5 Å.

  1. Select STI A 201. Include its chain and residue identifier so the chain B copy is excluded.
  2. Select protein atoms within 5 Å of that ligand, then expand the selection to whole residues. Showing only the nearby atoms can make side chains appear broken.
  3. Show the selected residues as sticks while leaving the rest of the protein as a cartoon. Centre the view on the ligand and pocket.
  4. Label a few useful residues, including Thr315, Met318 and Glu286. These are examples to inspect, not a complete interaction list.

Record: Name three pocket residues within 5 Å of STI. Which one is the gatekeeper residue?

Check: STI and the selected side chains are complete, and the residue labels are readable.

Optional PyMOL selection commands

These commands use the full 1IEP file and restrict the protein selection to chain A. If PyMOL gives your loaded object a different name, replace 1IEP in the commands with the name shown in the object panel.

select ligand, 1IEP and chain A and resn STI and resi 201
select pocket, byres ((1IEP and chain A and polymer.protein) within 5 of ligand)
show sticks, ligand or pocket
zoom ligand or pocket
Step 4

Measure contacts

Use geometry and chemistry together when discussing an interaction.

  1. Open Wizard → Measurement, then pick one ligand atom and one nearby protein atom. Display their distance in Å.
  2. Inspect possible polar contacts between the ligand and pocket. Keep only the contacts you can explain clearly in the image.
  3. For each proposed interaction, identify the two atoms, residue name and measured distance. Inspect Thr315, Met318 and Glu286 first. Consider whether the atoms could act as donor or acceptor, or carry charge.
  4. Check whether waters, alternate conformations, missing hydrogens or uncertain protonation could change the interpretation.

Record: Give one atom pair and its distance. Is a short heavy-atom distance alone enough to call it a hydrogen bond?

Check: You can explain at least one displayed distance without treating every short contact as a confirmed hydrogen bond.

Optional command for possible polar contacts

This creates a measurement object for putative polar contacts. Inspect the geometry and chemistry yourself.

distance possible_polar_contacts, ligand, pocket, 3.5, mode=2
Step 5

Compare structures

Look for changes that could matter near the binding site.

  1. Load 1M52.pdb as a second object. This structure contains PD173955 as P17. In chain A its ligand residue number is 119. Give the second protein a contrasting colour.
  2. Superpose the protein chains, then inspect both the whole-protein alignment and the local ligand-binding region.
  3. Compare the imatinib and PD173955 positions, Thr315 and the activation loop. Find Lys271 and Glu286 in each structure and measure the shortest distance between their charged side-chain atoms.
  4. Toggle one object off and on to see which features belong to each structure.

Record: One similarity and one difference between the binding sites. How does the Lys271-Glu286 distance compare between structures?

Check: You can point to one local difference after aligning chain A of each structure.

Optional alignment command
align (1M52 and chain A and polymer.protein), (1IEP and chain A and polymer.protein)
Step 6 · guided demonstration

Inspect surface and charge

Compare the pocket's shape with the ligand and a prepared electrostatic view.

  1. Show the protein surface around the selected binding site. Rotate the view to judge whether the ligand sits in a groove, cavity or exposed region.
  2. If the instructor provides an APBS electrostatic map, inspect areas with different potential near charged or polar parts of the ligand.
  3. Return to the cartoon-and-sticks view before moving on. A surface can hide important atom-level contacts.

Check: You can describe one observation about shape or charge complementarity without treating the image as a binding-energy calculation.

Step 7 · guided demonstration

Explore a mutation

Use a side-chain change to form a testable structural question.

  1. Open Wizard → Mutagenesis and select Thr315 in chain A of 1IEP.
  2. Change it to isoleucine and inspect several proposed side-chain rotamers.
  3. Look for a possible clash or a changed contact with the ligand. Compare the proposed side chain with the original one.
  4. Leave the wizard without treating a suggested rotamer as an experimentally observed mutation.

Think: What contact or space near STI might change? What would require experimental testing?

Check: You can state one plausible effect and one reason the model alone cannot establish it.

Step 8

Save your work

Keep both an editable scene and a figure that another person can understand.

  1. Return to a clean binding-site view with the ligand, complete nearby residues, a few useful labels and any measured distance you want to show.
  2. Use File → Save Session As to save a .pse file. This preserves the scene so you can edit it later.
  3. Use File → Save Image to export an annotated PNG. Check that labels, ligand and key residues are visible at the saved size.
  4. Open the saved files once to confirm that they are usable.

Check: Your session reopens and your image shows the ligand-binding site clearly.
